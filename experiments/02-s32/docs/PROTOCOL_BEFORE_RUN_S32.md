# FoR S32 — протокол до запуска

Дата: 2026-10-28. Цель: проверить, устраняет ли введение в Ядро FoR достаточности относительно конкретного действия дефицит при малом бюджете, обнаруженный в S31.

Источник: неизменная S31 (хранится отдельно). Миры: ровно те же публичные три двоичных признака и шесть законов, тот же B2, изолированные SQLite агента и симулятора, без передачи скрытого закона.

Предрегистрация: сравнить базовую T=S30, новую T32 и B2 на 12 парах (6 законов × 2 привязки) при бюджете 4; затем проверить бюджет 12 и изменение закона/цели при большем бюджете. Физическое действие допускается лишь по действительному конкретному измерению того же состояния, не по отрицательным умолчаниям о непроверенных состояниях. Локальная модель должна быть явно помечена ограниченной областью применимости. При мониторинге нельзя трактовать ещё не изученную область как подтверждённо отрицательную. Отдельная абляция отключает новую локальную достаточность и должна вернуть S31-поведение. Перезапуск не дублирует физические квитанции.

Оцениваем: число допустимых действий, стоимость измерения, действие при недостатке оснований, пересмотр при изменении проверенного состояния, целостность, перезапуск, отсутствие утечки приватного закона, следы зависимостей. Не объявлять результат доказательством всего Разума, уникальности Ядра или превосходства над B2.

Отрицательный контроль: достаточность конкретного действия не равна истинности глобальной модели; вне измеренной точки система не имеет подтверждённого предсказания. При общей скрытой ошибке сенсоров достоверность измерения остаётся нерешённой.
