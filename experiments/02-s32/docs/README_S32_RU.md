# FoR S32

Новый ограниченный механизм Ядра: локальная достаточность проверенного действия без фиктивной глобальной модели. T32 сравнивается с тем же сильным B2 из S31; оригиналы S31 не изменены.

Запуск из `experimental`:
- `python -m unittest -q test_s32_core_sufficiency`
- `python s32_comparison.py` (48 пар)
- исторические испытания — отдельно по модулям в своих исходных версиях.

`FoR_КАРТА_ПОЛНОЙ_ПРОВЕРКИ.md` — матрица оставшихся частей всей теории, не объявляет полную верификацию.

Демонстрационный симулятор не должен иметь доступа к файлам пользователя. Контроль пути Python не считается OS sandbox. Испытания исходной S31 и всех предыдущих программ не переписаны. Файлы теории оставлены без изменений.

GUI предыдущей версии S31 включён для просмотра старых контуров; новый механизм S32 пока испытывается через `Run_S32.bat` / Python, отдельной новой графической вкладки не обещается.
