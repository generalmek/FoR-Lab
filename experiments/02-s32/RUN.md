# Эксперимент № 2 (S32): воспроизведение

1. Установите Python 3.13 с официального сайта Python. Дополнительных пакетов не требуется.
2. Windows: двойной щелчок `Run_Experiment_2.bat`; результаты сохраняются в `runs/`.
3. Альтернативно откройте `code/` и выполните `python -m unittest -q test_s32_core_sufficiency`, затем `python s32_comparison.py`.
4. Тесты исходного пакета: 13/13; сравнительные пары: 48.

## Где исходные контрольные результаты

- [Архив результатов](results/RAW_RESULTS_ARCHIVE.zip) содержит контрольные файлы и исходные данные.
- [Сводка S32 в составе кода](code/S32_SUMMARY.json) — доступная напрямую копия сводки.
- После запуска новая сводка сохраняется в `runs/S32_SUMMARY.json`. Не путайте её с отсутствующим историческим путём `results/S32_SUMMARY.json`.
- [Протокол до прогона](docs/PROTOCOL_BEFORE_RUN_S32.md) и [отчёт PDF](FoR_Experiment_2_Report_RU.pdf).

Внимание: первая пилотная кампания и исправленная кампания различаются; это отражено в отчёте. Проводите повторные испытания в отдельной копии, не перезаписывайте контрольные архивные результаты. Агент работает в ограниченном виртуальном симуляторе без разрешённого автономного доступа к личным файлам.
