# Эксперимент 2 (S32): воспроизведение

1. Установите Python 3.13 с официального сайта Python. Дополнительных пакетов не требуется.
2. Windows: двойной щелчок `Run_Experiment_2.bat`; результаты сохранятся в `runs/`.
3. Альтернативно откройте `code/` и выполните `python -m unittest -q test_s32_core_sufficiency`, затем `python s32_comparison.py`.
4. Тесты: 13/13; пары: 48; сравните `runs/S32_SUMMARY.json` с `results/S32_SUMMARY.json`.

Внимание: первая кампания и исправленная кампания различаются. См. `docs/AMENDMENT_AFTER_PILOT.md` и PDF. Новые запуски не должны изменять контрольные сырые данные в `results/`. Агент работает только внутри виртуального симулятора, не имеет автономного доступа к пользовательским дискам.
