# Повтор контрольного опыта

Из каталога `experiments/03-incubator` запустите:

```sh
python3 code/replay_corrections.py
```

Python 3.10 или новее, сторонние зависимости не нужны. Скрипт сравнивает ответы замороженного парсера 154 с публичным журналом. Успешное воспроизведение включает **один ожидаемый отрицательный результат**: парсер ошибочно связывает высоту и площадь как два значения одной величины.

Файлы результатов не перезаписываются. Это самостоятельное воспроизведение трёх контрольных случаев семантического разбора без OCR, внешних сервисов и частных материалов. Для полной серии 70/82 здесь опубликованы журналы прогонов, но не полная сборка FoR-Incubator.
