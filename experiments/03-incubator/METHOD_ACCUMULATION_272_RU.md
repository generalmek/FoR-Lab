# FoR 272 — накопительный цикл методов

26 ноября 2026. Автор теории: Mihail Tkalic. Инженерные опыты с участием ИИ, не независимая репликация. В самом исследуемом цикле LLM не использовалась.

## Протокол

Лабораторная надстройка над исходным интерпретатором и таблицами методов FoR 240, расширяющая поиск 271. Восемь парных серий, по три последовательных задачи (скрытые рецепты из 2, 4, 5 примитивов). База SQLite сохранялась и вновь открывалась между задачами. В каждой паре одинаковые графы, скрытые результаты, правила проверки и лимит 600000 учитываемых операций на задачу. Группа reuse строит до трёх токенов из примитивов и приобретённых методов (до пяти примитивов после развёртывания). Flat ищет непосредственно до пяти примитивов (до трёх в первом задании). Поиск выбирает различающие наблюдения в пределах двух очередных сцен; контрольная выборка отделена от отбора.

Независимый метод сохраняется при отзыве основания другого метода (отдельный контроль).

## Вывод

В пределах заданной грамматики приобретённая процедура может стать элементом построения следующей процедуры. Иерархическое сохранение сокращает пространство поиска, но создаёт зависимость новых методов от прежних оснований. Результат совместим с механизмом повторного использования конструкций в §7.9.1. Это не установление общего ускорения обучения.

## Ограничения

Порядок задач специально благоприятен для композиции; скрытые рецепты и графы генерирует стенд. Поиск сравнивает разные пространства гипотез, не чистую абляцию кэша. Число операций не включает всю стоимость Python, SQLite, хеширования и подготовки сцен. Точность переноса измерена только для валидированных методов. Пять серий reuse не завершили полную цепочку. Новые примитивы, самостоятельный выбор задач, автоматический ремонт всех зависимых методов после отзыва и подключение к планировщику рабочего Ядра не проверены. Рабочая сборка не изменялась. Исходники и журналы подготовлены локально; этот публичный файл является сводкой, не полной воспроизводимой публикацией.
