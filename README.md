## Run / Запуск
Python3.13, standard library only / только стандартная библиотека. After extraction / после распаковки:
```
cd research/integrated-2026-10-26
python verify_package.py
python -m unittest discover -q
python integrated_demo.py
```
The demo creates a new runs directory. Existing results are preserved. Earlier experiment modules are historical branches; not every module is part of the integrated inheritance chain.
Демонстрация создаёт новую папку runs. Исторические данные сохраняются. Не все старые экспериментальные ветви включены в общую сборку.

Read INTEGRATED_RESULTS_RU.md, PROCEDURAL_RESULTS_RU.md, DIAGNOSIS_RESULTS_RU.md and THEORY_AMENDMENTS_2026-10-26_RU.md. Earlier negative/control results are retained: the simple reward baseline outscored learned selection (2186 versus2164); no superiority claim.

Limits: given grammar, meanings, goals and resource reserve; trusted references; zero-noise finite affine sensor contract; simulator-trusted physical receipts; no general concurrency/crash guarantee. Calibration uses three paid probes per step. Search compute and operation budgets are separate. New external goals receive new budgets; repairs do not. Repair does not undo an earlier harmful action. Consciousness and autonomous value formation are untested.
Границы: заданные грамматика, значения, цели и резерв; доверенные эталоны; бесшумный аффинный канал; достоверная по устройству симулятора квитанция. Нет общей гарантии конкурентной/аварийной устойчивости. Ремонт не отменяет прежнего воздействия. Сознание и самостоятельное формирование ценностей не проверены.
