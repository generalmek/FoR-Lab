## Научный статус и воспроизводимость

Эти стенды демонстрируют исполнимость и тестируемость конкретных причинных механизмов. Они не устанавливают создание полного Разума, сознания, самостоятельных ценностей или ASI. Отсутствие преимущества над данным baseline не является опровержением всех положений теории, а требует различающих проверок и достаточно сильного независимо реализованного соперника.

Публичный релиз не содержит виртуальных окружений, личных данных и огромных промежуточных журналов. Программная лицензия пока не назначена: отсутствие `LICENSE` не означает общего разрешения на переиспользование.
